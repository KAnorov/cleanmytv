# CleanMyTV (русская версия)

Приложение для Mac и Windows к проекту [cleanyourtv](https://github.com/Gathin23/cleanyourtv) от
[@gathint](https://x.com/gathint). Оно очищает Android TV от лишнего, устанавливает чистый лаунчер и
позволяет его настроить — без Python, Java, Android Studio и `adb` на компьютере.

Это русскоязычный форк: интерфейс и документация переведены, логика и данные остались прежними.
Оригинальный README на английском — в [README.en.md](README.en.md).

Впервые здесь? **[Руководство пользователя](docs/USER-GUIDE.md)** проходит каждый шаг в темпе
владельца TV, включая откат и решение проблем, а **[таблица известных устройств](docs/KNOWN-DEVICES.md)**
показывает, какие модели покрывают встроенные списки. Этот README — технический обзор.

Это независимый проект, не часть cleanyourtv. Списки очистки, темы и лаунчер берутся из upstream без
изменений; это приложение — настольный интерфейс к ним. Проверено на Xiaomi Mi Box S под Windows.

## Скачивание и установка

Готовые сборки берите в [релизах оригинального проекта](https://github.com/wingedpanther/cleanmytv/releases)
(этот форк распространяется исходниками; сборка — см. раздел «Разработка»):

| Компьютер | Файл |
|---|---|
| Mac на Apple silicon (M1 и новее) | `CleanMyTV-<version>-arm64.dmg` |
| Mac на Intel | `CleanMyTV-<version>.dmg` |
| Windows 10 или 11 | `CleanMyTV-Setup-<version>.exe` |

Установщики не подписаны платным сертификатом разработчика, поэтому при первом запуске компьютер
предупредит:

- **Mac:** откройте dmg, перетащите CleanMyTV в «Программы» и запустите. Когда macOS скажет, что не
  может проверить разработчика, нажмите **Готово**, откройте «Системные настройки → Конфиденциальность
  и безопасность» и нажмите **Всё равно открыть** рядом с CleanMyTV (в macOS 14 и раньше — правый клик
  по приложению и **Открыть**). macOS спросит, можно ли CleanMyTV искать устройства в локальной сети:
  выберите **Разрешить**, иначе приложение не достучится до TV.

  Если macOS говорит, что CleanMyTV **повреждено и не может быть открыто**, у вас v0.1.0 с неправильно
  подписанной сборкой. Выполните в Терминале и откройте приложение снова:

  ```bash
  xattr -cr /Applications/CleanMyTV.app
  codesign --force --deep --sign - /Applications/CleanMyTV.app
  ```
- **Windows:** когда SmartScreen сообщит о защите ПК, нажмите **Подробнее**, затем **Выполнить в любом
  случае**.

## Перед началом: на TV

1. Настройки → Настройки устройства → О телевизоре (на некоторых Google TV: Настройки → Система →
   О телевизоре).
2. Нажмите OK на пункте **Сборка** (или **Сборка Android TV OS**) семь раз, пока TV не сообщит, что вы
   разработчик.
3. Вернитесь на экран назад → **Для разработчиков** → включите **Отладку по USB**. Если есть также
   **Отладка по сети** или **Отладка ADB**, включите и её.
4. Оставьте TV включённым и подключённым к той же Wi-Fi сети, что и компьютер.

Откройте CleanMyTV, найдите TV и выберите **Разрешить**, когда TV спросит. Поставьте галочку
**Всегда разрешать с этого компьютера**, чтобы не подтверждать каждый раз.

## Что делает приложение

| Шаг | Что происходит |
|---|---|
| **Подключение** | Проверяет сеть, ищет TV с открытым портом 5555, подключается и ждёт, пока вы нажмёте «Разрешить» на TV. Для Google TV, которые предлагают только отладку по Wi-Fi, появляется форма сопряжения. |
| **Очистка** | Подбирает upstream-список под модель вашего TV. Для каждого пакета показывает его текущее состояние и даёт выбрать, что отключить. Если модели нет в списке, предлагает пакеты, которые отключают на других TV. |
| **Лаунчер** | Устанавливает встроенный лаунчер и передаёт ему Home. Если Home не переключился, откатывает изменения. По желанию включает службы кнопок Input и Home. |
| **Настройка** | Перетаскивание приложений (первый ряд — док), скрытие приложений, число колонок и рядов, обои или набор сменяющихся обоев, затемнение, цвет фона, небо по времени суток, приветствие, праздничное оформление, анимация и назначение кнопок пульта. Сначала читает текущий `config.json` с TV и умеет делать снимок экрана. |
| **Дополнительно** | Заставка с часами, Private DNS с блокировкой рекламы, скорость анимации, язык лаунчера, экранный пульт, перезагрузка. |
| **Завершение** | Пошагово выключает отладку и проверяет, что порт 5555 закрыт. |

| | |
|---|---|
| ![Подключение к TV](docs/setup.png) | ![Очистка: список под TV и состояние каждого пакета](docs/clean-up.png) |

Ничего не удаляется. Пакеты отключаются только для вашего пользователя, а «Восстановить» возвращает
все пакеты в состояние до первой очистки.

## Как вернуться к настройке

Снова включите отладку по USB и откройте приложение — оно подключится к TV, который использовался
последним. Если чистый лаунчер уже Home, приложение сразу откроет «Настройку» с текущими данными TV.
После работы снова выключите отладку. Если вы не отзывали разрешения, запроса «Разрешить» не будет.

Если роутер выдал TV новый адрес или по старому адресу отвечает другое устройство, приложение сообщит
об этом и просканирует сеть. TV выбираете вы; приложение не входит автоматически в устройства, которые
нашло сканированием.

## Безопасность и приватность

- **С чем связывается.** Только с выбранным адресом TV по ADB на порту 5555 в локальной сети.
  Необязательные загрузки (Java, Android SDK, Google `adb`, исходники лаунчера) идут с Adoptium,
  dl.google.com и GitHub по HTTPS и только по нажатию. Источники фона в «Настройке» обращаются к
  www.bing.com или к api.themoviedb.org и image.tmdb.org с вашим ключом TMDB и только когда вы ими
  пользуетесь. Никакой аналитики, аккаунтов и собственного сервера.
- **Ваши ключи.** Приложение создаёт собственный ключ ADB в своей папке данных и подписывает только им.
  Оно никогда не использует `~/.android/adbkey`, которому могут доверять ваши телефоны, и входит
  только по выбранному вами адресу. Сетевой ADB передаёт данные открытым текстом — используйте его в
  сети, которой доверяете.
- **Закреплённый upstream.** Списки, темы и исходники лаунчера берутся из одного закреплённого коммита
  в [`upstream.json`](upstream.json) с хешем содержимого. Сборка отвергает несовпадение, поэтому
  изменения в upstream попадают в приложение только после проверки и обновления закрепления.
- **Ключ подписи лаунчера намеренно лежит внутри приложения.** `resources/signing/cleanmytv.jks`
  (пароль `cleanyourtv`) определяет установленный вручную лаунчер для обновлений, чтобы копия из
  «Сборки из исходников» ставилась поверх встроенной. Доступа к TV он не даёт: для установки всё равно
  нужен ADB-доступ, разрешённый владельцем.
- **Выключайте отладку после работы.** Некоторые TV (`ro.adb.secure=0`) принимают любое устройство в
  сети без запроса разрешения; приложение предупредит, если у вас такой. Шаг «Завершение» проверяет,
  что порт 5555 закрыт. Лаунчеру отладка не нужна.
- **Защита окна.** Окно приложения изолировано, не может уйти со своей страницы, и только этой странице
  разрешено вызывать часть, которая общается с TV.

Нашли проблему безопасности? Сообщите о ней приватно через страницу репозитория
**Security → Report a vulnerability**, а не в публичном issue.

## Связь с upstream

Приложение — это порт `tools/` и `launcher/build-and-install.sh` из upstream на TypeScript:

- `src/main/adb/` — ADB-клиент поверх TCP, аналог `tools/tv.py`.
- `src/main/debloat.ts` содержит те же защиты, что `disable.sh`: не отключит приложение, владеющее Home,
  пока его некому заменить, и не отключит setupwraith, пока тому принадлежит Wi-Fi сеть. Он пишет ту же
  запись восстановления в `~/.cleanyourtv/`, плюс имя устройства TV, чтобы запись переезжала вместе с TV
  на новый адрес. `tests/engine.test.ts` проверяет, что имена в записи и команды восстановления точно
  совпадают с upstream `recovery.py`, поэтому `tools/restore.sh ~/.cleanyourtv/lists/<tv>.txt` тоже
  может отменить сделанное приложением.
- `src/main/launcher.ts` повторяет порядок передачи Home из `build-and-install.sh`: установить, запустить,
  отключить штатный лаунчер, назначить Home, проверить, откатить.
- `src/main/theme.ts` отправляет то же, что `tools/theme.sh`, с тем же перезапуском.

### APK лаунчера

Приложение содержит лаунчер, собранный `npm run apk` из закреплённого коммита upstream. Этот скрипт
скачивает JDK 17 и Android SDK в `.cytv-build/` так же, как это делает «Сборка из исходников» в
приложении, и обе сборки используют один ключ подписи. `resources/launcher.json` хранит коммит upstream,
из которого собран APK.

Лаунчер, собранный собственным скриптом upstream, подписан отладочным ключом того компьютера. Приложение
замечает несовпадение и спрашивает перед заменой, потому что переустановка теряет порядок плиток,
заданный на TV.

## Разработка

```bash
npm install
npm run sync                 # списки и темы из закреплённого коммита upstream
npm run apk                  # resources/launcher.apk (первый запуск скачает ~800 МБ инструментов)
npm run dev                  # приложение с горячей перезагрузкой
npx tsx scripts/fake-tv.ts   # «ненастоящий» TV на 127.0.0.1:5556, чтобы попробовать без телевизора
UPSTREAM_DIR=<клон на закреплённом коммите> npm test
npm run dist:mac             # dist/*.dmg   (на Mac)
npm run dist:win             # dist/*.exe   (на Windows, Mac или в CI)
```

Чтобы перейти на более новый upstream: изучите изменения, затем `node scripts/pin-upstream.mjs <commit sha>`,
`npm run sync`, `npm run apk` и проверьте на TV. `UPSTREAM_UNPINNED=1` разрешает `sync` и `apk` брать
другое содержимое для локальной проверки.

`.github/workflows/build.yml` собирает APK на Linux и запускает тесты при каждом push и pull request.
Push в `main` и теги версий также собирают установщики macOS и Windows; их можно скачать в **Artifacts**
запуска. Workflow работает с правами только на чтение, а actions закреплены по коммитам.

### Выпуск версии

1. Установите новую `version` в `package.json` и закоммитьте.
2. Поставьте тег и отправьте: `git tag v0.1.1 && git push origin main v0.1.1`.
3. Workflow соберёт оба установщика и откроет **черновик** релиза с ними. Проверьте и нажмите
   **Publish release**.

Тег должен совпадать с версией в `package.json`, иначе шаг релиза остановится.

## Известные ограничения

- Порядок плиток и выбор приложений, сделанные на TV, хранятся в приватном хранилище лаунчера, которое
  ADB не читает. Приложение задаёт порядок через `dock_apps`, и он имеет приоритет над порядком на TV.
- Имена приложений берутся из встроенной таблицы популярных TV-приложений. Для остальных имя строится
  из пакета; собственные названия и иконки TV не читаются.
- Сопряжение по Wi-Fi использует Google `adb`, скачиваемый по требованию. На macOS доступ к локальной
  сети может блокировать этот бинарник. Если сопряжение там не проходит, выполните его с Windows или
  один раз запустите `adb pair` в Терминале.
