# CleanMyTV для Android

Отдельное Android-приложение, которое делает основное без компьютера:

- находит телевизоры в Wi-Fi сети и подключается к ним по ADB (порт 5555);
- показывает список пакетов из встроенного upstream-списка и отключает выбранные;
- сохраняет точку восстановления и умеет включить пакеты обратно — все сразу или по одному;
- показывает отдельный экран «Что отключено» и ловит «хвосты» после обновления прошивки;
- выгружает скрипт отката `.sh` или `.ps1`: его можно запустить на любом компьютере с adb;
- меняет настройки самого TV: Private DNS с блокировкой рекламы и скорость системных анимаций;
- устанавливает встроенный лаунчер CleanYourTV 2.4 и назначает его Home;
- настраивает вид главного экрана с телефона: сетка, док, приветствие, скрытые плитки и обои;
- возвращает штатный лаунчер;
- собирает отчёт о телевизоре, по которому модель можно добавить в список очистки;
- проверяет обновления приложения по релизам в GitHub.

Требования: Android 10 или новее, телефон и TV в одной Wi-Fi сети, на TV включена
**«Отладка по USB»** (и «Отладка по сети»/«Отладка ADB», если есть). При первом подключении TV
спросит разрешение — нажмите **«Разрешить»** и включите **«Всегда разрешать с этого компьютера»**.

## Установка

Скачайте APK из релиза `android-v0.3.1` на странице релизов форка и установите на телефон,
разрешив установку из неизвестных источников. APK подписан постоянным ключом проекта, поэтому
следующие версии ставятся поверх без удаления приложения.

## Как пользоваться

Внизу экрана пять вкладок: **Подключение**, **Очистка**, **Вид**, **Отключено** и **Ещё**.

1. **Подключение.** Введите IP-адрес TV (Настройки → Сеть) и нажмите «Подключить» — или нажмите
   «Найти телевизоры», и приложение само проверит адреса в вашей сети. На TV подтвердите запрос
   отладки.
2. **Очистка.** Проверьте список, снимите галочки с нужных приложений и нажмите «Отключить».
   Перед изменением сохраняется точка восстановления. Кнопка «Восстановить» возвращает всё как было.
3. **Вид.** Настройки встроенного лаунчера: сколько приложений в ряду, док, подписи, приветствие,
   обои, скрытые плитки. Изменения уходят на TV по кнопке «Сохранить на TV», лаунчер перезапускается
   и сразу показывает новый вид.
4. **Отключено.** Список только тех пакетов, которые отключило это приложение. Любой можно вернуть
   по одному. Если после обновления прошивки TV включил что-то обратно, сверху появится блок
   «Вернулось после обновления прошивки» с кнопкой «Отключить снова».
5. **Ещё.**
   - **Лаунчер.** «Установить лаунчер», затем «Сделать по умолчанию»: приложение назначит новый
     лаунчер Home и отключит штатные, чтобы после перезагрузки не возвращался старый экран.
   - **Настройки TV.** Private DNS (`dns.adguard-dns.com`) режет рекламу на уровне DNS во всех
     приложениях; множители анимаций `0.0` убирают задержки меню. Обе настройки обратимы, значения
     видны на экране, перед изменением спрашивается подтверждение.
   - **Отчёт о телевизоре.** Текст без адресов и серийников: модель, версия Android, что отключено.
     Его можно скопировать или сохранить файлом и вставить в новую задачу — так модель попадает
     в общий список.
   - **Обновления.** «Проверить обновления» находит последний релиз на GitHub. Если он новее,
     появляется кнопка «Обновить до …»: APK скачивается в кеш и открывается системный установщик,
     который ставит новую версию поверх текущей. При первом обновлении нужно разрешить установку
     из CleanMyTV на открывшемся экране.

Если что-то пошло не так, на экране «Очистка» нажмите «Восстановить», на экране «Отключено» —
«Вернуть» у одного пакета, а на экране «Лаунчер» — «Вернуть штатный лаунчер».

## Что нового в 0.3.1

- **Обновление из приложения.** Кнопка «Проверить обновления» показывает новую версию и предлагает
  установить её: APK скачивается с GitHub, системный установщик ставит его поверх текущей версии.
- **Постоянная подпись.** Сборки из CI и локальные подписаны одним ключом проекта, поэтому
  обновление больше не требует удаления приложения.

## Что было в 0.3.0

- **Настройка вида лаунчера с телефона.** Приложение читает и пишет `config.json` в папке
  лаунчера на TV, обновляет `theme_revision` и перезапускает Home. Поддерживаются сетка (4–8
  колонок и 0–3 ряда), док, приветствие, скрытые плитки, анимации и обои 1920×1080 — картинка
  обрезается под 16:9 на телефоне. Всё это без пересборки лаунчера.
- **«Что не трогаем».** На экране очистки рекомендованные пакеты сгруппированы по разделам
  списка, а пакеты, которые в списке помечены как нужные TV, спрятаны в раскрывающийся блок.
- **Запасной набор для неизвестной модели.** Если точного списка нет, показываются только пакеты,
  которые отключают во всех известных списках этого производителя.
- **Отчёт о телевизоре.** Готовый текст для задачи «список для такой-то модели».
- **Новый интерфейс.** Нижняя навигация, карточки, переключатели и слайдеры вместо длинного списка
  галочек; прогресс и сообщения видны на любом экране.

## Сборка

Локально нужен Android SDK 35 и JDK 17:

```bash
gradle -p android assembleDebug
```

Или вручную запустите workflow **Android APK** в GitHub Actions. Push тега `android-*` создаёт
релиз с APK.

## Ограничения

- Сопряжение по Wireless debugging с кодом не поддерживается: нужен открытый порт 5555.
- Приложение не собирает лаунчер из исходников: используется встроенный APK 2.4.
- Порядок плиток в доке пока задаётся только в настольной версии; в приложении можно скрывать
  плитки и менять сетку, но не перетаскивать их.
- Ключ подписи лежит в репозитории: это осознанный компромисс, иначе APK из CI не смог бы
  обновлять установленное приложение. Магазинная публикация с таким ключом не планируется.
