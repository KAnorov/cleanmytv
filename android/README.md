# CleanMyTV для Android (MVP)

Отдельное Android-приложение, которое делает основное без компьютера:

- подключается к TV по Wi-Fi через ADB (порт 5555);
- показывает список пакетов из встроенного upstream-списка и отключает выбранные;
- сохраняет точку восстановления и умеет включить пакеты обратно;
- устанавливает встроенный лаунчер CleanYourTV 2.4 и назначает его Home;
- возвращает штатный лаунчер.

Требования: Android 10 или новее, телефон и TV в одной Wi-Fi сети, на TV включена
**«Отладка по USB»** (и «Отладка по сети»/«Отладка ADB», если есть). При первом подключении TV
спросит разрешение — нажмите **«Разрешить»** и включите **«Всегда разрешать с этого компьютера»**.

## Установка

Скачайте APK из релиза `android-v0.1.1` на странице релизов форка и установите на телефон,
разрешив установку из неизвестных источников. APK отладочный и не подписан магазинным
сертификатом.

## Как пользоваться

1. Введите IP-адрес TV (Настройки → Сеть) и нажмите «Подключить».
2. На TV подтвердите запрос отладки.
3. На экране «Очистка» проверьте список, снимите галочки с нужных приложений и нажмите
   «Применить». Перед изменением сохраняется точка восстановления.
4. На экране «Лаунчер» нажмите «Установить лаунчер», затем Home на пульте TV.

Если что-то пошло не так, на экране «Очистка» нажмите «Восстановить», а на экране «Лаунчер» —
«Вернуть штатный лаунчер».

## Сборка

Локально нужен Android SDK 35 и JDK 17:

```bash
gradle -p android assembleDebug
```

Или вручную запустите workflow **Android APK** в GitHub Actions. Push тега `android-*` создаёт
релиз с APK.

## Ограничения MVP

- Только подключение, очистка и лаунчер. Настройка темы, обоев, заставки, DNS и пульта пока
  остаётся в настольной версии.
- Нет автоматического поиска TV по сети — вводится IP-адрес.
- Приложение не собирает лаунчер из исходников: используется встроенный APK 2.4.
- APK подписан отладочным ключом; при переустановке может потребоваться сначала удалить старую
  версию.
